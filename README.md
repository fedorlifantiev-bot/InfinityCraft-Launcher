# InfinityCraft-Launcher
EN
Premium cross-platform Minecraft launcher built with .NET 8, Avalonia UI 11 and ReactiveUI. Features Microsoft and offline profiles, modpack management, skin editor, custom game overlay, auto-updates, glassmorphism UI and modern MVVM architecture.
RU
Премиальный кроссплатформенный Minecraft-лаунчер на .NET 8 и Avalonia UI с Microsoft/offline-профилями, модпаками, редактором скинов, игровым оверлеем и автообновлениями.
